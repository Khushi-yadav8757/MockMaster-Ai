# 🤖 MockMaster AI — AI Mock Interview Platform

MockMaster AI is an intelligent **AI-powered mock interview platform** designed to simulate real interview experiences.
It helps students practice technical and HR interviews with real-time feedback, voice interaction, and performance tracking.

🌐 **Live Demo:**
https://mock-master-ai.vercel.app

# 🚀 Features

* 🎤 **AI Mock Interviews** — Practice realistic interview sessions
* 🧠 **Dynamic AI Questions** — Real-time generated questions
* 🔊 **Voice Interaction** — Speech-based responses
* 📊 **Performance Tracking** — Store responses and feedback
* 🗂 **Multiple Interview Types**

  * Technical DSA
  * HR & Behavioral
  * System Design
* ☁ **Cloud Database Integration** — Supabase backend
* ⚡ **Fast Deployment** — Hosted on Vercel
* 🎯 **User-Friendly UI** — Clean and modern interface

# ⚙️ Installation & Setup

## Step 1 — Clone the Repository

```bash
git clone https://github.com/Khushi-yadav8757/MockMaster-Ai.git
cd MockMaster-Ai
```

---

## Step 2 — Install Dependencies

```bash
npm install
```

---

## Step 3 — Run the Project Locally

```bash
npm run dev
```

Project will run on:

```bash
http://localhost:8080
```

---

# 🔑 Environment Variables

Create a `.env` file and add:

```env
VITE_SUPABASE_PROJECT_ID=your_project_id
VITE_SUPABASE_PUBLISHABLE_KEY=your_key
VITE_SUPABASE_URL=your_supabase_url
```

---

# 🌐 Deployment

This project is deployed using **Vercel**.

## Steps:

1. Push code to GitHub
2. Import repository into Vercel
3. Add environment variables
4. Click Deploy
