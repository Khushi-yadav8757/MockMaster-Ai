# MockMasterAI – AI Mock Interview Platform

MockMasterAI is an AI-powered mock interview platform designed to help students practice technical and HR interviews with real-time feedback.

## 🚀 Features

- AI-based mock interview simulation  
- Voice-enabled interview mode  
- Multiple interview categories  
- Real-time feedback system  
- Modern responsive UI  

## 🛠 Tech Stack

- React.js  
- TypeScript  
- Tailwind CSS  
- Supabase  
- Web Speech API  

## 📌 Purpose

This project was developed to help students improve their interview skills through realistic mock interview simulations.
